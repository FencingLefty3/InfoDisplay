# Info Display

A split flap style, standby inspired AFK/background display.
![screenshot](image.png)

## Features

- Single face clocks
    - gradiant (color customizable)
    - world clock (customizable)
    - info complications
    
- Double complication clocks
    - date
    - time
    - battery
    - event (customizable)
## Using Site

Open the site


[https://fencinglefty.com/InfoDisplay](https://fencinglefty.com/InfoDisplay)

Scroll up and down for different types of clock faces/complications.

Scroll left and right for double and single panes.


## Run Locally

Clone the project

```bash
  git clone https://github.com/FencingLefty3/InfoDisplay
```

Go to the project directory

```bash
  cd InfoDisplay
```

Start the LocalHost

```bash
  python -m http.server
```
